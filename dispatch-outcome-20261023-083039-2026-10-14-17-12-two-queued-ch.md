## What changed (branch dispatch/20261023-083039-…, not pushed)

`backend/line_relay.py`:

- **Per-day send ledger** — `_deliver` and the /send bulk park bump
  counters on today's row: `push_calls`, `push_msgs` (bubbles, the
  quota-metered unit), `reply_calls`, `reply_msgs`, `parked_msgs`,
  `push_failed`. Write-through to `LINE_SEND_LEDGER`
  (`~/.local/share/ada/line-send-ledger.json`). Day rollover emits one
  `send_rollup` ops event per nonzero day — checked on every ledger
  touch and each poll so an idle relay still rolls the day out.
- **Quota poller** — `_quota_poller` runs a free `_quota_probe` every
  `LINE_QUOTA_POLL_S` (3600 default, 0 disables): journals
  used/limit/remaining, emits `quota_status` (info), `quota_low`
  (warn) when `remaining <= LINE_QUOTA_WARN` (30 default), or
  `quota_depleted` + re-arms `_quota_blocked` when spent (idempotent —
  quiet while already blocked). Unlimited plans never fire quota_low.
- **GET /quota** gains `ledger_today` and `month_push_msgs` (the
  relay's own month-to-date burn, no API read needed).

`.env.example` documents the three new knobs. Tests:
`tests/test_line_relay_quota.py` +11 (SendLedger class);
`test_line_relay_parked.py` helper also redirects `SEND_LEDGER_FILE`
so unit tests never write the real ledger.
